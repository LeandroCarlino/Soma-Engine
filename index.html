SOMA ENGINE v3.3

Entorno interactivo con aceleración por hardware (WebGL) y simulación de estados.

Controles: Escribe comandos simples o combina palabras clave. Los estados visuales se restauran de forma gradual.

Sinergias: Combinar palabras afines puede desatar efectos ocultos en la simulación.

AVISO VISUAL

Este entorno utiliza distorsión cromática, efectos de post-procesado intenso y destellos dinámicos. Si tu sistema pide menos movimiento, se reducen automáticamente.
